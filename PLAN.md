## 2. Стандарт конспекта

Каждый новый конспект — файл `src/content/sheets/<slug>.html` с одним только телом
страницы (без `<html>`, `<head>` и `<style>`) плюс запись в `src/data/sheets.js`.
Структура тела повторяет `oop.html`:

1. Метаданные (`title` вида «Тема — конспект Junior / Middle / Senior», `description` с перечислением всех тем через запятую) — в записи `src/data/sheets.js`. CSS копировать не нужно: `base.css` подключается сам, специфичные для страницы правила кладутся в `src/styles/pages/<slug>.css` и добавляются в поле `styles`.
2. `header.hero`: eyebrow, h1, 3 абзаца `.lead` (третий — маршрут по конспекту и ссылки на смежные темы), блок `.audience` из трёх карточек, строка `.stats` со счётчиками.
3. `nav.toc`: оглавление, сгруппированное Junior / Middle / Senior / Справочник.
4. Три секции уровней (`lvl-j`, `lvl-m`, `lvl-s`), в каждой 4–8 карточек `article.card` и завершающий чек-лист уровня.
5. Справочник: `#tables` (сравнительные таблицы), `#cheatsheet` (шаблоны, конфиги, команды), `#interview` (60 вопросов: 20/20/20), `#practice` (15 заданий), `#plan` (4 недели + блок «Что помогает на собеседовании»).
6. `footer.foot` со ссылкой на `index.html`.

Сквозная нумерация таблиц по всему документу (`Таблица N · ...` в `caption` и в бейдже карточки справочника).

**После добавления конспекта обновить витрину** (`src/content/sheets/index.html`): карточка в `.catalog`, строка в `#map`, счётчик «Конспектов» в `.stats` и в `footer`.
